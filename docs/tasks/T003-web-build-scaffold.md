## Goal
`npm ci`, `npm run build`, `npx tsc --noEmit`, ESLint, Prettier and Vitest all succeed inside `web/`, on an
app that renders one placeholder element. Asset URLs in `dist/index.html` are relative, so the base path can
be a runtime setting.

## Interface contract

`web/package.json` — exact versions from doc 09 §1; the three marked lines are resolved by `npm install`:

```json
{
  "name": "dl-tool-web", "private": true, "type": "module",
  "scripts": {
    "dev": "vite", "build": "tsc --noEmit -p tsconfig.json && vite build",
    "lint": "eslint .", "test": "vitest run"
  },
  "dependencies": { "react": "19.2.8", "react-dom": "19.2.8" },
  "devDependencies": {
    "@testing-library/react": "16.3.3", "@types/react": "*", "@types/react-dom": "*",
    "@vitejs/plugin-react": "6.1.1", "eslint": "10.9.1", "happy-dom": "*",
    "prettier": "3.9.6", "typescript": "5.9.3", "typescript-eslint": "8.69.0",
    "vite": "8.2.2", "vitest": "4.1.11"
  }
}
```

<!-- pin at implementation time: @types/react, @types/react-dom, happy-dom -->

`web/vite.config.ts`:

```ts
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';

export default defineConfig({
  base: './',
  plugins: [react()],
  build: { outDir: 'dist', emptyOutDir: true },
  test: { environment: 'happy-dom', include: ['src/**/*.test.{ts,tsx}'] },
});
```

`web/src/main.tsx`:

```tsx
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';

export function App() {
  return <div data-testid="app-root">dl-tool</div>;
}

const host = document.getElementById('root');
if (host) createRoot(host).render(<StrictMode><App /></StrictMode>);
```

## Steps
1. Create `web/package.json` with the block above; run `npm install` to produce `web/package-lock.json` and
   to resolve the three `*` versions into exact strings.
2. Create `web/tsconfig.json`: `"target": "ES2022"`, `"module": "ESNext"`, `"moduleResolution": "bundler"`,
   `"jsx": "react-jsx"`, `"strict": true`, `"noEmit": true`, `"include": ["src"]`.
3. Create `web/vite.config.ts` exactly as above. `base` stays `'./'`; the base path is injected at serve time
   by T013, never baked in at build time.
4. Create `web/eslint.config.js` as an ESLint 10 flat config exporting `typescript-eslint`'s recommended
   configuration for `src/**/*.{ts,tsx}`, ignoring `dist`.
5. Create `web/index.html` with `<div id="root"></div>` and `<script type="module" src="/src/main.tsx">`.
6. Create `web/src/main.tsx` exactly as above, and `web/src/main.test.ts` rendering `App` and asserting the
   `app-root` element carries the text `dl-tool`.
7. Run `npm run build` once and confirm `dist/index.html` references its assets relatively (`./assets/...`),
   then delete `dist/`; it is generated, not committed.
8. Run the verification command and paste its output under `## Evidence`.
