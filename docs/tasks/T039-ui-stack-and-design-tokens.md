## Goal
`npm run build` produces a bundle that loads Tailwind 4, the shadcn/ui primitives M3 needs, and one token
sheet defining every colour in light and dark, and references no external origin. `applyTheme` puts
`class="dark"` on `<html>` from the stored choice before first paint.

// web/src/lib/theme.ts
export type ThemeChoice = 'system' | 'light' | 'dark';

/** The prefs document written by T045; a malformed or absent value yields 'system'. */
export function readStoredTheme(): ThemeChoice;
export function storeTheme(choice: ThemeChoice): void;
/** 'system' resolves through matchMedia('(prefers-color-scheme: dark)'). */
export function resolveTheme(choice: ThemeChoice): 'light' | 'dark';
/** Adds or removes class="dark" on document.documentElement. Idempotent. */
export function applyTheme(choice: ThemeChoice): void;

## Steps
1. Edit `web/package.json` with the dependency block above, then run `npm install` to update
   `web/package-lock.json`. Add no package doc 09 §1 lists as deliberately absent.
2. Edit `web/vite.config.ts`: import `@tailwindcss/vite` and add `tailwindcss()` to `plugins`, and add
   `resolve.alias` mapping `@` to `./src`. Leave `base: './'` exactly as T003 set it.
3. Create `web/src/index.css` exactly as above. Every colour is defined once on `:root` and overridden by
   name under `.dark`; never define a colour only inside a media query.
4. Run `npx shadcn@4.19.1 init` and accept the Vite + Tailwind defaults, producing `web/components.json`
   and `web/src/lib/utils.ts`.
5. Run `npx shadcn@4.19.1 add button checkbox dialog drawer input label select popover context-menu tabs
   tooltip sonner` once, so every M3 dialog has its primitive already copied in.
6. Create `web/src/lib/theme.ts` exactly as above. `readStoredTheme` parses `localStorage['dl.ui.prefs.v1']`
   inside a `try`/`catch` and returns `'system'` on any failure.
7. Create `web/src/i18n.ts` and `web/src/locales/en/common.json` holding the app title, the theme labels
   (`System`, `Light`, `Dark`) and the empty-state sentences of doc 09 §10.5.
8. Edit `web/src/main.tsx` to `import './index.css'` and call `applyTheme(readStoredTheme())` before
   `createRoot`, so the first paint is already in the right theme.
9. Create `web/src/lib/theme.test.ts`: `resolveTheme('system')` follows a stubbed `matchMedia`;
   `applyTheme('dark')` adds the class and `applyTheme('light')` removes it; a corrupt stored value yields
   `'system'`.
10. Run the verification command and paste its output under `## Evidence`.
