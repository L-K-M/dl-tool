## Goal
`make build` produces `bin/dl-tool`, which starts, logs one structured line and stops cleanly on SIGTERM.
`go.mod` records every dependency the plan names, at the exact pinned version where one exists.

## Steps
1. Run `go mod init github.com/L-K-M/dl-tool` and set the `go` directive to `1.26`.
2. `go get` each module in the block above at its exact pinned version, then `go get` the six unpinned
   modules with no version suffix.
3. Do **not** run `go mod tidy`. The five modules that no package imports yet would be dropped, and their
   pinned versions would be lost.
4. Create `internal/obs/log.go` implementing `NewLogger`: `slog.NewJSONHandler` for `json`,
   `tint.NewHandler` for `text`, both with a `slog.HandlerOptions{Level: …}` parsed from `level`.
5. Create `cmd/dl-tool/main.go` with the shape above. Call `slog.SetDefault(obs.NewLogger(os.Stdout,
   "info", "json"))` before the hooks are registered; T005 replaces those two literals with configuration.
6. Add a `version` subcommand printing `version`, the Go version and the VCS revision from
   `runtime/debug.ReadBuildInfo`.
7. Log one `info` record on start and one on stop, so a container operator sees the lifecycle.
8. Run the verification command and paste its output under `## Evidence`.

## Acceptance criteria
