# AGENTS.md — dl-tool

dl-tool is a self-hosted replacement for Synology Download Station, deployed with Docker Compose.
It is a **control plane**: it owns the unified queue, users, destinations, search, RSS, scheduling and
the web UI, and delegates the actual transferring to aria2, qBittorrent and yt-dlp.

**This repository currently contains the plan, not the implementation.** Your job is to build it.
[`IMPLEMENTING.md`](IMPLEMENTING.md) is the standing brief for doing that: the task loop, the
one-task-one-PR rule, when to stop, and what is still undecided.

## Where the plan lives

- **Start at [`docs/00-INDEX.md`](docs/00-INDEX.md).** It is the map and the reading order.
- Work is defined **one task per file** in `docs/tasks/`. Pick the next task from
  [`docs/tasks/00-task-index.md`](docs/tasks/00-task-index.md).
- **Never start coding without opening the task file.** The task file is authoritative; this file only
  tells you where things are.
- Every *why* lives in [`docs/decisions/`](docs/decisions/). Do not re-argue a decision — if you think one
  is wrong, write it under `## Blocked` in the task file and stop.

## How to pick the next task

Take the topmost row in `docs/tasks/00-task-index.md` whose `Status` is `todo` and whose every
`Depends on` entry is `done`. Open that file and follow it. Do not read other task files.

## Hard rules

1. NEVER modify a file that is not listed in the current task file's `Files` table. If you believe you
   must, STOP and write why under `## Blocked` in that task file.
2. NEVER skip, xfail or delete a test, weaken an assertion, or add `//nolint` / `_ = err` to make a check
   pass. Fix the cause.
3. NEVER add a dependency without an ADR in `docs/decisions/`, and never change a pinned version.
4. NEVER hardcode a path, port, URL or secret. Every one of them is a setting defined in
   [`docs/11-config-reference.md`](docs/11-config-reference.md).
5. NEVER copy a fact between documents. Each fact has exactly one home (see `docs/00-INDEX.md`); link to it.
6. NEVER ship a bundled indexer for a piracy site, and never execute third-party definition code —
   no PHP, no Python plugins, no scripting runtime. See
   [`ADR-0010`](docs/decisions/0010-never-execute-third-party-definitions.md).
7. ALWAYS finish a task by running its `## Verification` block, pasting the real output into that task
   file's `## Evidence` section, and setting its status to `done` in the task index — in the same commit.

## Conventions

Full detail in [`docs/14-conventions.md`](docs/14-conventions.md). The short version:

- Go 1.26, `internal/` layout, `CGO_ENABLED=0`, errors wrapped with `%w`, `log/slog` only.
- Frontend: React 19 + Vite + TypeScript 5.9.3, in `web/`. Never call `fetch` directly — use the
  generated `openapi-fetch` client.
- Bytes and bytes per second everywhere. Unix milliseconds in the database, RFC 3339 in the API.
- Branch `task/T0NN-slug`; commit message `T0NN: <imperative summary>`; one commit per task.

## Do not edit

- `docs/decisions/*` — append a new ADR instead of editing an accepted one.
- `api/openapi.json` and `web/src/api/schema.d.ts` — both are generated by `make gen`.
